ОБЪЕКТ — ПАСПОРТА ОБЪЕКТОВ
==========================

САМЫЙ ПРОСТОЙ СПОСОБ
--------------------
1) Один раз установите Node.js LTS: https://nodejs.org
   (Windows: обычный установщик .msi. Дальше ничего настраивать не нужно.)

2) Запустите файл в этой папке (двойной клик):
     - Windows:  ЗАПУСТИТЬ-САЙТ.bat
     - macOS:    ЗАПУСТИТЬ-САЙТ.command
     - Linux:    ЗАПУСТИТЬ-САЙТ.sh

   Первый запуск занимает пару минут: скачиваются зависимости и собирается
   сайт. Дальше запуск занимает 2-3 секунды. Откроется окно с логами и браузер.

3) В окне с логами будет написан АДРЕС и ПАРОЛЬ администратора:
     Сайт:      http://localhost:3000
     Панель:    http://localhost:3000/admin
     Пароль:    (случайный, генерируется при первом запуске)
   Пароль также хранится в файле .env.local в этой папке.


ЧТО ДАЛЬШЕ
----------
- Зайдите в панель, создайте коллекцию, объект, добавьте фото и нужное число
  страниц, скачайте QR-код (кнопка «QR-код») и распечатайте паспорт (кнопка
  «Печать» — формат A6).
- Остановить сайт: закрыть окно с логами или Ctrl+C.


МЕЛОЧИ
------
- Если порт 3000 занят, сайт поднимется на 3001, 3002 и т.д. — адрес будет
  написан в окне логов.
- Демо-данные (для тренировки, можно удалить): npm run seed
- Один раз проверить, что всё работает: npm run smoke
- Данные и фотографии лежат в папке data — её и нужно копировать/бэкапить.
- Перенести на сервер (VPS): см. README.md, раздел «Перенос на VPS».
